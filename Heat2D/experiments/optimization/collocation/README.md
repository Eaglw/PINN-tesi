# Optimization: Collocation Points Analysis

This experiment compares the performance of the PINN using standard resolution (50x50 collocation points) vs high resolution (100x100).

## Artifacts
- `std_res/`: Results for standard resolution.
- `high_res/`: Results for high resolution.
- `plots/`: Comparison plots.
- `Heat2D_optim_collocation.py`: The script used for this experiment.
