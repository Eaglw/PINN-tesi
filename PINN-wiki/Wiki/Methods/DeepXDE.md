# Method: DeepXDE

DeepXDE is a popular library for Physics-Informed Machine Learning, designed to simplify the implementation of PINNs.

## Features
- **Library Independence**: Supports TensorFlow and PyTorch as backends.
- **Complex Geometries**: Built-in support for sampling in irregular domains.
- **Standardized API**: Provides clear abstractions for defining domains, PDEs, and boundary conditions.

## Usage in Literature
- Employed in [[Hazra_et_al_Convective_Heat_Transfer]] for jet impingement cooling analysis.
